# GTM test landing page (sandboxed)

A neutral, de-branded landing page used only to debug a Google Tag Manager container
(`GTM-KL5W86TH`) in Tag Assistant / Preview. No real data is sent: `js/sandbox-blocker.js`
blocks and logs all outbound tracker calls. Not affiliated with any real company.

- `registration-accounting-test/` — form page (fires page-load tags + `form_submit`)
- `thank-you/` — path contains "thank" to trigger conversion tags
